# آکادمی عربی

سایت ایستا و بدون نیاز به نصب وابستگی. هر بازی در پوشهٔ `منابع` فایل HTML، CSS و JavaScript مستقل دارد (`1.html` تا `7.html` و فایل‌های هم‌نام `.css` و `.js`) و همچنان از داخل لابی سه‌بعدی آکادمی اجرا می‌شود. ظاهر بازی‌ها با لایه‌های عمق، سطح‌های برجسته و حرکت‌های سبک هماهنگ با اتاق مطالعهٔ سرمه‌ای و طلایی تقویت شده است؛ سؤال‌ها، مرحله‌ها و قواعد بازی حفظ شده‌اند. بازی هفتم نیز بدون وابستگی به Tailwind CDN اجرا می‌شود.

نسخهٔ اصلی لوگوی ارسالی در `assets/academy-logo-source.png` نگه‌داری شده و نسخهٔ شفاف و برش‌خوردهٔ وب در `assets/academy-logo.png` استفاده می‌شود.

موسیقی زمینهٔ ارسالی در `assets/academy-background-music.mp3` با حجم کمتر از ۴ مگابایت به‌کار می‌رود. پخش با اجازهٔ مرورگر در آغاز یا نخستین تعامل کاربر شروع می‌شود و دکمهٔ ثابت «پخش/توقف موسیقی» در لابی و هنگام اجرای همهٔ بازی‌ها در دسترس است.

برای اجرای محلی، یک وب‌سرور ایستا را در پوشهٔ پروژه اجرا کنید؛ برای نمونه:

```powershell
python -m http.server 8000
```

سپس `http://localhost:8000/` را در مرورگر باز کنید. بازی‌ها با بازکردن مستقیم فایل `index.html` هم داخل قاب اجرا می‌شوند؛ برای افکت‌های مشترک قاب، سایت و بازی‌ها را از وب‌سرور و هم‌مبدأ باز کنید. اگر بارگذاری بازی ناموفق شد، از «تلاش دوباره» استفاده کنید یا آن را با پیوند «باز کردن جداگانه» اجرا کنید. نمایش آغازین را می‌توان رد کرد و حرکت‌های غیرضروری، از جمله حرکتِ ابزارهای تحریر، با تنظیم «کاهش حرکت» دستگاه غیرفعال می‌شوند.
